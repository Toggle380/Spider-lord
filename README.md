# Spider Lord — мод для Minecraft Forge 1.20.1

Стань владыкой (владычицей) пауков.

## Как играть
1. Скрафти **Сердце Владыки пауков**:
   ```
   паутина  глаз паука  паутина
   глаз паука  бродильный глаз паука  глаз паука
   паутина  глаз паука  паутина
   ```
2. **ПКМ с Сердцем** — стать Владыкой. Облик меняется на женско-паучий.
3. **ПКМ владыкой** — призвать паучий рой (перезарядка 30 с).
4. **Shift + ПКМ** — вернуть человеческий облик.

## Способности
- **Лазание по стенам**: упрись в стену и держи «вперёд» или «прыжок». Shift — прилипнуть, иначе медленно сползаешь.
- **Паутина**: в каждом блоке, который ты прошёл, остаётся паучий шёлк (исчезает через 20 с). Липнет ко всем, кроме пауков и владык.
- **Пауки в подчинении**: не нападают на тебя, идут следом и атакуют того, кого ты ударил или кто ударил тебя (радиус 32 блока).
- **Ядовитый укус**, иммунитет к яду, падение причиняет на 70% меньше урона, +15% к скорости.
- Состояние сохраняется после смерти.
- **Доение**: ПКМ **пустым ведром** по Владыке — получишь ведро молока (раз в 30 с на одного игрока).

## Сборка
1. JDK 17.
2. Положи в папку проекта `gradlew`, `gradlew.bat` и `gradle/` из официального MDK Forge 1.20.1-47.2.0
   (или выполни `gradle wrapper --gradle-version 8.1.1`).
3. `./gradlew build` — готовый мод будет в `build/libs/spiderlord-1.0.0.jar`.
4. Для запуска из среды: `./gradlew runClient`.

Текстуры лежат уже готовые; при желании перегенерировать: `python3 tools/gen_textures.py`.
